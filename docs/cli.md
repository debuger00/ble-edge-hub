# 命令行交互

在终端直接运行 `./build/ble-iot-edge`。输入 `help` 查看命令，`q` 退出。

- `list` / `ls`：显示网关，以及全部配置设备的 ID、MAC、类型、中文连接状态、最近扫描 RSSI、扫描时间及距今秒数、最近电量和更新时间。
- `devices`：ID、MAC 与类型对照表。
- `connect 0 005` / `disconnect 0 005`：按设备 ID 操作。数字 ID 可简写成 `5`（需唯一），也支持完整 MAC。
- `gateway-info 0`：查询网关信息，结果显示于后续日志。
- `scan-on 0`：开启扫描输出并查询网关信息。
- `stats`：查看数据管道和队列状态。

命令名不区分大小写，空行直接重新显示提示符。连接、断开请求排队不表示设备已完成操作，应通过 `list` 或后续日志确认。
定时采集开启时，时段外禁止连接，时段内手动断开的设备暂停自动重连，下一次采集时段重新开始时恢复。

电量为当前进程最近收到的有效百分比。设备或网关断线后仍保留，服务重启后重新获取。
更新时间采用本机时区，并显示距今秒数。没有回复时显示“暂无记录”，不能视为 0%。
当前电量查询间隔由 `config/config.yaml` 的 `battery_interval_seconds` 控制，现为 300 秒。
“就绪”表示连接及通知初始化完成，不保证持续收到有效采样。

## 自动连接调度

已恢复原来的批量提交方式：网关接入且处于采集时段时，将所有启用设备的连接请求加入队列，逐条发送，不增加启动等待和固定连接间隔。
每 `reconnect_interval_seconds`（当前 60 秒）检查一次未连接设备；已 searching/connecting/ready 的长连接交由网关继续处理，不重复下发。
`gateway-info` 可手动查询状态；不再周期性发送无进展查询。

单台设备可设置 `enabled: false` 禁止连接并跳过报警，保留 ID/MAC 展示；不会主动拆除网关中已存在的连接。
当前 003 保持禁用。修改配置后重启生效。
