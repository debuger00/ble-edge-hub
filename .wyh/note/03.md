明白了。你的问题是：为什么不在 `tcp_server.cpp` 里重新写：

```cpp
class TcpServer {
public:
    void start() {
        // 实现
    }

    void stop() {
        // 实现
    }
};
```

而是写：

```cpp
void TcpServer::start() {
    // 实现
}
```

核心原因是：**`TcpServer` 类已经在头文件中完整定义过了，`.cpp` 中不能再定义一次同名类。**

## 1. 头文件中已经定义了类

`tcp_server.hpp` 中：

```cpp
class TcpServer {
public:
    TcpServer(...);
    ~TcpServer();

    void start();
    void stop();

private:
    void accept_loop();
    int listen_socket_;
};
```

这已经是一次完整的类定义。它确定了：

* 有哪些成员函数；
* 有哪些成员变量；
* 哪些是 `public`、`private`；
* `TcpServer` 对象占用多少内存；
* 类的整体结构。

而 `tcp_server.cpp` 开头会包含这个头文件：

```cpp
#include "iot/services/tcp_server.hpp"
```

所以编译 `tcp_server.cpp` 时，编译器已经看到了 `TcpServer` 的完整定义。

---

## 2. `.cpp` 中再次写 `class TcpServer` 会变成重复定义

如果再写：

```cpp
#include "tcp_server.hpp"

class TcpServer {
public:
    void start() {
    }
};
```

相当于在同一个作用域中定义了两次 `TcpServer`，会出现类似错误：

```text
error: redefinition of 'class TcpServer'
```

它不是“补充原来的类”，而是试图**重新定义一个同名类**。

C++ 不允许通过下面的方式分多次补充类：

```cpp
class TcpServer {
    void start();
};

// 错误：不能重新打开类，再补充内容
class TcpServer {
    void stop();
};
```

C++ 的类定义不像某些语言的扩展类机制：类的大括号关闭后，就不能再次用 `class TcpServer {}` 打开并补充实现。

---

## 3. `TcpServer::start()` 是对原声明的实现

头文件中：

```cpp
class TcpServer {
public:
    void start();  // 声明
};
```

`.cpp` 中：

```cpp
void TcpServer::start() {
    // 实现
}
```

这句话表达的是：

```text
下面实现的是 TcpServer 类中已经声明过的 start 函数
```

`::` 指明函数所属的类：

```cpp
TcpServer::start
//  ^类作用域  ^成员函数
```

如果不写 `TcpServer::`：

```cpp
void start() {
}
```

这就变成了一个普通函数，与 `TcpServer::start()` 不是同一个函数。

---

## 4. 能不能把整个类只写在 `.cpp` 中？

可以，但此时不要再在头文件中定义它：

```cpp
// tcp_server.cpp

class TcpServer {
public:
    void start() {
        // 实现
    }

private:
    int listen_socket_;
};
```

但是这样一来，其他 `.cpp` 文件就看不到 `TcpServer` 的定义，无法正常使用它：

```cpp
// main.cpp

TcpServer server; // 错误：不知道 TcpServer 是什么
server.start();
```

即使头文件中只进行前置声明：

```cpp
class TcpServer;
```

其他文件也只知道“存在这样一个类”，但不知道：

* 它有哪些函数；
* 它有哪些成员；
* 它占多少内存。

因此不能直接创建对象：

```cpp
TcpServer server;  // 错误：类型不完整
```

---

## 5. 为什么必须把类结构放在头文件中？

假设 `main.cpp` 需要使用：

```cpp
TcpServer server(config, database, websocket, inference);
server.start();
```

编译 `main.cpp` 时，编译器必须知道：

```cpp
class TcpServer {
public:
    TcpServer(...);
    void start();
    void stop();
    // ...
};
```

所以这些声明需要放在 `tcp_server.hpp` 中，让 `main.cpp` 通过 `#include` 看到。

但是 `main.cpp` 不需要知道 `start()` 内部具体如何创建 Socket。因此函数体放在 `tcp_server.cpp`：

```cpp
void TcpServer::start() {
    listen_socket_ = create_listener(...);
    accept_thread_ = std::thread(&TcpServer::accept_loop, this);
}
```

最后由链接器把调用和函数实现连接起来。

---

## 6. 两种写法本质上的区别

### 全部写在类里面

```cpp
// tcp_server.hpp

class TcpServer {
public:
    void start() {
        // 完整实现
    }
};
```

所有包含此头文件的 `.cpp` 都会看到函数实现。

### 声明与实现分开

```cpp
// tcp_server.hpp

class TcpServer {
public:
    void start();
};
```

```cpp
// tcp_server.cpp

void TcpServer::start() {
    // 完整实现
}
```

其他文件只看到接口，具体实现只编译一次。

---

一句话总结：

> `class TcpServer {}` 是定义类的整体结构，不能在头文件和 `.cpp` 中各写一次；`TcpServer::start()` 是在类定义结束后，实现其中已经声明的成员函数。`::` 正是 C++ 用于分离类声明与函数实现的语法。
